FILES
  index.html          the site
  about.html          "About me" page (own RU/EN texts inside the file)
  build.py            builds works.json from works/
  works.json          list of works (generated by build.py)
  works/              your works go here

STRUCTURE   works/<category>/<group>/<file>
  works/emoji/T2X2/heart.tgs        -> "Emoji and stickers" / T2X2
  works/emoji/YAMAKASI/cat.webm     -> "Emoji and stickers" / YAMAKASI
  works/vector/T2X2/logo.svg        -> "Vector" / T2X2
  works/vector/TRUDI/mark.svg       -> "Vector" / TRUDI

  Category = first folder (emoji, vector). Group = second folder.
  Both are taken from where the file lies, file type does not matter.
  Folder name is shown as written. Use latin names, no spaces.
  New group = new folder inside emoji/ or vector/.
  File name = work title. Order = file name order (01_, 02_ ...).
  Files: .tgs .json .webm .mp4 .svg .png .webp .gif .jpg

PLAYBACK
  Animations are off by default. When a group is scrolled to for the first time
  all its animations play once and stop. They do not restart on scrolling back.
  Click an emoji to turn it on (loops), click again to pause.

AFTER ADDING FILES
  python build.py
  git add -A && git commit -m works && git push

LOCAL PREVIEW
  python -m http.server 8000   then open http://localhost:8000
