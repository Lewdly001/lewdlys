FILES
  index.html   the site
  assets/banner.jpg   banner picture (replace the file to change it)
  build.py     builds works.json from works/
  works.json   list of works (generated by build.py)
  works/       your works go here

STRUCTURE
  works/emoji/T2X2/       .tgs .json .webm .mp4
  works/emoji/YAMAKASI/
  works/lottie/
  works/vector/TRUDI/      .svg

  works/<group>/<subgroup>/<file>. Files can also lie right in a group.
  The banner at the top shows the emoji group (works/emoji) with a switch by subfolder.
  Deeper folders are not read. Use latin folder names.
  Subfolder names are shown on the site exactly as written (T2X2, TRUDI).
  Group names (emoji, lottie, vector) are set in build.py (NAMES).
  New subgroup = new folder. File name = work title. Order = file name order (01_, 02_ ...).

AFTER ADDING FILES
  python build.py
  git add -A && git commit -m works && git push

LOCAL PREVIEW
  python -m http.server 8000   then open http://localhost:8000
