FILES
  index.html   the site
  build.py     builds works.json from works/
  works.json   list of works (generated by build.py)
  works/       your works go here

WORKS
  works/emoji-stickers/   .tgs .json .webm .mp4
  works/lottie/     .tgs .json .webm .mp4
  works/vector/     .svg

  Folder = group. Group names on the site are set in build.py (NAMES).
  New group = new folder (latin name).
  File name = work title. Order = file name order (01_, 02_ ...).

AFTER ADDING FILES
  python build.py
  git add -A && git commit -m works && git push

LOCAL PREVIEW
  python -m http.server 8000   then open http://localhost:8000
