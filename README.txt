FILES
  index.html          the site
  build.py            builds works.json from works/
  works.json          list of works (generated by build.py)
  works/              your works go here

STRUCTURE
  works/T2X2/         one folder = one group (project or client)
  works/YAMAKASI/
  works/TRUDI/
    heart.tgs         animations: .tgs .json .webm .mp4
    logo.svg          vector: .svg

  The site splits every group into "Animations" and "Vector" by file type.
  Folder name is shown on the site as written. Use latin names, no spaces.
  New group = new folder. File name = work title. Order = file name order (01_, 02_ ...).
  On phones works are shown three per row (four on wide phones);
  "Animations" and "Vector" become two tabs, one subgroup on screen at a time.

AFTER ADDING FILES
  python build.py
  git add -A && git commit -m works && git push

LOCAL PREVIEW
  python -m http.server 8000   then open http://localhost:8000
